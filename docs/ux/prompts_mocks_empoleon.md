# Mocks con IA - AquaPort Enterprise

Debido a las políticas de cuotas de generación de imágenes por hardware en esta sesión, he diseñado minuciosamente los **5 Prompts de Generación (Ingeniería de Prompts)** optimizados para modelos como Midjourney v6, DALL-E 3 o Imagen. 

Estos prompts contienen toda la narrativa visual y semántica necesaria para renderizar el flujo Enterprise con el Design System oscuro que definimos.

## Los 5 Prompts de Generación de UI

### 1. Mapa de las 4 zonas hídricas con drones en tiempo real
**Prompt:**
> *Modern web dashboard UI design, drone fleet management software, dark mode with deep slate blue background (#0F172A). Main screen shows a high-tech top-down hydrographic map of 4 water reservoirs (Z1, Z2, Z3, Z4) connected by rivers. Glowing cyan dots representing aquatic drones (ID: D-01, AR-02) moving on the water. Glassmorphism panels on the left showing active zones. Clean typography, neon blue accents, highly detailed data visualization, dribbble style, 8k resolution, no device frames --ar 16:9*

### 2. Configuración de ruta multi-etapa con waypoints
**Prompt:**
> *Modern dashboard UI design, dark mode, route planning screen for aquatic drones. A sleek map showing a path drawn with a glowing neon line from point A to point C, passing through waypoint B. A sidebar panel displaying route configuration: "Origen: Embalse Z1", "Waypoint: Canal Central", "Destino: Laboratorio Z4", "Carga: Muestra de Agua (0.5kg)". Minimalist UI, translucent glass panels, cyan and emerald green UI elements, futuristic but clean data, high quality UX, no device frames --ar 16:9*

### 3. Monitoreo de progreso por tramo
**Prompt:**
> *Real-time monitoring dashboard UI for aquatic drones, dark mode. A horizontal progress bar showing a multi-stage delivery route broken into segments. Active segment highlighted in cyan.
